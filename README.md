# S7 : cours, TD, TP

Structure par module : `Cours/ | TD/ | TP/ | Revisions/`, plus `Projet/` quand le module en a un.

- `_Planning/examens.md` : coefficients et dates (à compléter)
- `_Planning/calendrier.md` : calendrier jour par jour du 6 nov. 2026 au 31 janv. 2027
- `_Planning/S7-revisions.ics` : le même calendrier, à importer dans Calendrier (iPhone)
- `_Planning/plan-hebdo.md` : répartition du temps par catégorie
- `<Module>/Revisions/fiche.md` : fiche de révision
- `<Module>/Revisions/erreurs.md` : journal d'erreurs, refaire à J+3

Ajouter un document : le déposer dans le bon sous-dossier, puis `git add -A && git commit -m "ajout" && git push`.
